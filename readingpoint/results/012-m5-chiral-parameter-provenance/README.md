# Result 012 — M5 chiral parameter provenance

## Outcome

**P2 CHIRAL SUBSTRATE MACHINERY IMPLEMENTED; P2 → N4 PARAMETER BRIDGE NOT ESTABLISHED.**

The examined M5 source contains an implemented chiral Lifshitz substrate term in the P2 heliknoton branch.

That construction uses the coefficient structure

`2 * q0 * Lc`

together with a Frank elastic partner

`Kf = Lc / 2`

in the tested helix and heliknoton sweep.

The N4 CP construction instead introduces a separate coefficient:

`g_chiral`

No explicit derivation or parameter mapping from the P2 substrate quantities

`q0`, `Lc`, `Kf`

to the N4 coefficient

`g_chiral`

was found in the examined source paths.

## P2 chiral substrate

The P2 heliknoton implementation explicitly introduces a Landau-de Gennes
chiral Lifshitz term of the form

`F_chiral = ∫ 2 q0 Lc ε_ikl Q_ij ∂_k Q_lj d³r`

with

`q0 = 2π / p`

for helix pitch `p`.

The implementation therefore contains an explicit substrate-level chiral
coefficient structure:

`2 * q0 * Lc`

The corresponding code path stores:

`q0`

`Lc`

`Kf`

as parameters of the energy functional.

In the tested helix and heliknoton construction, the Frank coefficient is
locked to the chiral constant through

`Kf = Lc / 2`

The source comments state that the Frank partner is required together with
the chiral cross-term to form the tested cholesteric free-energy
construction.

## Implemented P2 checks

The P2 branch contains explicit numerical checks of the chiral machinery.

These include:

- a finite-difference gradient check of the chiral term;
- comparison between the Taichi energy and an independent NumPy chiral-energy implementation;
- a Frank-term gradient check;
- a helix-favorability test;
- helix calibration;
- and a chiral-strength sweep of the heliknoton construction.

The examined source therefore goes beyond merely naming a possible
Lifshitz term.

A chiral substrate term is implemented as part of an executable M5
energy functional in this branch.

## N4 chiral sector

The N4 CP construction uses a complex Hermitian mass matrix of the form

`M_H = M_real + i * g_chiral * C`

where `C` is the geometric chiral-overlap matrix.

Result 011 reproduced the N4b chiral-origin baseline and found:

`g_chiral = 0 → delta_CP = 0, theta13 = 0`

while nonzero `g_chiral` activates the reproduced CP sector.

At

`g_chiral = 0.94`

the reproduced result was approximately

`delta_CP = -90°`

`theta13 = 8.581°`

Result 011 also found that the geometric overlap `C` is nonzero and
independent of `g_chiral`, while the achiral M5 LdG energy remains
degenerate between the tested `+chi` and `-chi` configurations.

The remaining question was therefore whether `g_chiral` could be traced
to an independently implemented M5 substrate term.

## Provenance test

Result 012 examined the relevant P2 and N4 source paths for an explicit
parameter bridge.

The P2 branch contains:

`q0`

`Lc`

`Kf`

and the Lifshitz coefficient structure

`2 * q0 * Lc`.

The N4 branch contains:

`g_chiral`.

Within the examined implementation, no expression was found of the form

`g_chiral = f(q0, Lc, Kf, ...)`

and no normalization, projection, overlap reduction, or effective-theory
step was found that derives `g_chiral` from the P2 substrate parameters.

Therefore the existence of the P2 Lifshitz term does not by itself fix
the value of the N4 chiral coefficient.

## Result

The executable/source-level comparison supports:

**P2 chiral substrate machinery:** IMPLEMENTED

**P2 Lifshitz coefficient structure:** `2 * q0 * Lc`

**P2 Frank partner in tested construction:** `Kf = Lc / 2`

**N4 chiral coefficient:** `g_chiral`

**Explicit P2 → N4 parameter bridge:** NOT FOUND IN EXAMINED SOURCES

**N4 `g_chiral` provenance:** FREE / PHENOMENOLOGICAL IN EXAMINED BRANCH

This resolves one part of the question raised by Result 011.

M5 does contain implemented chiral substrate machinery.

It does not yet establish that the N4 `g_chiral` parameter is the
effective coefficient generated by that machinery.

## Relation to Result 011

Result 011 established:

- nonzero geometric chiral overlap `C`;
- achiral handedness degeneracy;
- CP conservation at `g_chiral = 0`;
- CP activation for nonzero `g_chiral`;
- and no achiral physical orientation selector in the tested N4 model.

Its open question was whether the required chiral coupling had an
independent M5 substrate origin.

Result 012 sharpens that answer.

An implemented chiral Lifshitz substrate term exists in the P2 branch.

However, the examined source does not propagate its parameters into the
N4 mass-matrix coefficient.

The current status is therefore stronger than

`chiral substrate term absent`

but weaker than

`N4 g_chiral derived from the M5 substrate`.

The supported statement is:

**M5 contains implemented chiral substrate machinery, while the examined
N4 chiral coefficient remains without an explicit provenance bridge to
that machinery.**

## Relation to Result 009

Result 009 showed that opposite half-winding sign readouts depend on the
orientation of the chosen wound-plane basis.

It concluded that a physical sign convention requires an independently
specified orientation, handedness, transport rule, or interaction
observable.

Result 011 showed that the achiral N4 construction does not supply such an
energetic handedness preference.

Result 012 identifies a concrete M5 substrate mechanism capable of carrying
handedness information: the P2 Lifshitz term.

However, because the P2 → N4 effective-parameter bridge has not been
established, this does not yet satisfy the Result 009 orientation
requirement for the Reading Point → M5 mapping.

## Constraint

Result 012 is a provenance result.

It does not establish that

`g_chiral = 2 * q0 * Lc`

or any other direct identification.

The quantities occur in different constructions and may differ in units,
normalization, projection, geometric factors, or effective degrees of
freedom.

No conversion should be introduced by matching numerical values or by
dimensional appearance alone.

A valid bridge must arise from the M5 equations or from an independently
specified reduction of the P2 substrate energy into the N4 overlap
description.

## Next reading point

Determine whether the P2 Lifshitz energy can be reduced onto the N4
three-state overlap construction.

The next test should look for an effective coefficient multiplying the N4
antisymmetric chiral matrix `C`.

Rather than assigning

`g_chiral = 2 * q0 * Lc`

by hand, the test should construct the relevant N4 loop configurations,
evaluate the implemented P2 chiral functional on them, and determine
whether the resulting interaction matrix is proportional to the existing
N4 `C`.

If proportionality exists, measure the coefficient:

`C_P2 ≈ g_eff * C_N4`

and test whether `g_eff` is stable across controlled geometry and
discretization changes.

That would provide an executable P2 → N4 provenance bridge.

If proportionality fails, the result would establish that the current N4
`g_chiral * C` interaction is not the direct effective reduction of the
examined P2 Lifshitz term.

The Reading Point residue structure should remain outside that test until
the M5-side chiral provenance is established.
